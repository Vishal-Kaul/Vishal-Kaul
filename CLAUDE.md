# Vishal's Assistant: build spec for Claude Code

A public AI assistant on Vishal Kaul's portfolio (vishaluxi.framer.website). Visitors ask about his work, see case-study details beside the chat, request a call slot, or leave a message. Vishal gets a private summary in an inbox. Design is in Figma file HzFN3pk9sdTa12G5pPetzm, page "Assistant screens" (8 screens). Facts live in `assistant-facts.md`.

## Product rules (never break)
- Says it is an AI in the first message and in the footer line.
- Never commits Vishal to anything. Call slots are "tentative until Vishal confirms".
- No pay or salary talk: "that's for Vishal, I'll pass it on".
- Never gives his phone number. Never mentions AlphaGrep.
- Never invents facts. If not in assistant-facts.md: say so and offer to take a message.
- Warm, friendly, short answers. Voice replies are 1 to 3 sentences.
- Call windows: Mon to Fri, 11 to 1 and 4 to 6 IST. Open to full-time, contract and freelance. Available immediately.

## Screens to build (match Figma)
1. Welcome: chat card left, dark "Ask me about Vishal's work" stage right (3 proof tiles, I can / I can't).
2. Case study on stage: tabs (Overview, Users, Design decisions, Results), headline, illustration, "Open full case study". The assistant switches the stage when a project comes up.
3. Voice mode: orb, Listening state, waveform, live caption, Mute / End voice / Text.
4. Scheduling: day chips, window chips, "Request" button, weekly windows grid on stage.
5. Message sent confirmation.
6. Vishal's inbox (private, behind login): conversation list (New / Needs you / All), summary card with Role, Call window, Reach, "Needs your call" flag, transcript, actions (Call back, Confirm slot, Reply by email).
7 and 8. Mobile welcome and case-study bottom sheet.

## Design language (matches his site)
- Font: Fira Sans (Regular, Medium, SemiBold, Bold), slight negative letter-spacing.
- Colours: page #FFFFFF, wash #F5F5F5, ink #1A1A1A, muted #6B6B6B, subtle #9A9A9A, line #E6E6E6, link/brand blue #127BB0, brand tint #E6F1F7, dark stage #1A1A1A, positive #2E7D5B.
- Pills (radius 99) for chips and buttons; 24px radius cards; one soft shadow on the chat card.
- Motion: calm. Orb breathes while listening, bars follow mic level, stage cross-fades.

## Suggested stack
Next.js (App Router) + Tailwind; Claude API for chat (streaming) with the facts file as system context and a `show_project` tool plus `propose_slot` and `take_message` tools; browser voice via Web Speech API first (swap for a realtime voice API later); Postgres or Supabase for conversations; Resend for the summary email; simple auth for the inbox.

## Cost and safety
- Cap messages per conversation and conversations per IP per day; cap voice minutes.
- Rate limit, log everything, flag prompt-injection attempts.
- Summary card is generated by a second Claude call at the end of each conversation.

## Build order
1. Static screens 1, 2, 7, 8 from Figma with mocked replies.
2. Chat with streaming + facts file + tools driving the stage.
3. Scheduling and message flow, save to DB, email summary.
4. Inbox (screen 6).
5. Voice mode.
6. Guardrail tests: 20 adversarial prompts (pay, phone number, commitments, made-up facts).
